* `databricks aitools` commands now send usage telemetry on how each run went (started, steps reached, outcome, error category), and the CLI records when it recommends installing Databricks AI tools. To upload it, `aitools update`, `list`, `version` and `uninstall` now contact the configured workspace like `aitools install` does: auth resolves in the background, and at the end of a run the command waits for it (at most 3 seconds) and then for the upload (`DATABRICKS_CLI_TELEMETRY_TIMEOUT`, default 3 seconds), so a short run can take up to about 6 seconds longer on a slow workspace and lasts at least 3 seconds while connections to the workspace are refused or time out. Set `DATABRICKS_CLI_DISABLE_TELEMETRY=1` to skip both. ([#7467](https://github.com/databricks/cli/pull/7467), [#7469](https://github.com/databricks/cli/pull/7469), [#7470](https://github.com/databricks/cli/pull/7470))
