* `databricks aitools install --output json` now reports `SKILLS_FETCH_FAILED`, `RELEASE_LOOKUP_FAILED` or `RATE_LIMITED` as the `error_category` when fetching skills fails, `MANIFEST_INVALID` for a skills manifest it cannot parse, `STATE_INVALID` for a corrupt install state file, and `PLUGIN_CLI_TIMEOUT` when a coding agent's CLI does not answer in time.
